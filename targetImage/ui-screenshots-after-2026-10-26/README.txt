LƯU Ý VỀ DỮ LIỆU CHỤP
API đăng nhập hiện trả HTTP 503 do Keycloak không sẵn sàng. Vì vậy, để có thể chụp đủ các màn hình sau đăng nhập, bộ ảnh dùng JWT giả lập chỉ ở trình duyệt và fixture API giả lập qua Puppeteer. Đây là ảnh review giao diện với dữ liệu demo, không phải ảnh chụp phiên đăng nhập thật của ba tài khoản, cũng không đại diện dữ liệu production. Tất cả request API trong lúc chụp được chặn và trả fixture cục bộ; không lưu, xóa, duyệt, nhận đơn, thanh toán, đổi voucher hoặc gửi tin nhắn lên backend.
